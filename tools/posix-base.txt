# Symbols of the C standard library (ISO/IEC 9899:2011) and of POSIX.
#
# This file separates, in the J4 measurement, the two families of symbols
# that real QNX code calls:
#
#   * the *standard* symbols (C standard, POSIX.1-2008, XSI): they are also
#     in the QNX C Library Reference, but they are not QNX-specific;
#   * the *QNX-specific* symbols: io_open, resmgr_attach,
#     iofunc_read_default, ThreadCtl, ConnectAttach, MsgSend, slogf,
#     InterruptMask, mmap_device_memory, devctl, ... Those are the ones the
#     J4 sheet targets.
#
# The list is **independent of the QNX corpus**: it does not come from the
# QNX documentation, so it cannot favour the tool. It is deliberately
# GENEROUS: a standard name forgotten here is simply treated as a
# QNX-specific symbol, which makes the measurement more demanding, not
# easier.
#
# Format: one name per line, comments start with "#".
