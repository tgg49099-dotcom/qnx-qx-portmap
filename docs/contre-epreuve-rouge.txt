Contre-epreuve ROUGE de QX PORTMAP
=================================

Une contre-epreuve rouge casse volontairement une regle du code, une par
une, et verifie que le test charge echoue. Un test qui passe toujours ne
teste rien.

Ce fichier conserve la sortie reelle des deux executions du 26/11/2026 sur
l'arbre du commit mesure ci-dessous :

  1. avec le corpus fige present  -> 12 / 12 contre-epreuves concluantes
  2. sans le corpus fige          -> 11 / 11 contre-epreuves concluantes,
                                     1 regle non testable (corpus absent)

Commit mesure : 5691e561386ffb87ce559aeafaf8ee713e811ca5

Le code que ces 12 regles cassent n'a pas change depuis cette mesure, et
cette condition est verifiee automatiquement par tools/published_counts.py,
qui est un des huit controles de scripts/verify-all.sh :

    git diff --name-only 5691e56 -- qnx_portmap/ 'tests/test*.py' \
        tools/contre_epreuve.py
    git ls-files --others --exclude-standard -- qnx_portmap/ 'tests/test*.py' \
        tools/contre_epreuve.py

ne listent aucun fichier.  Les fichiers modifies depuis le 26/11/2026 - les
documents, le manifeste, tools/published_counts.py et
tests/verify_all_contract.py, que la decouverte `unittest discover -s tests
-t .` ne prend pas car elle ne prend que les fichiers nommes test*.py - ne
changent ni le code casse ni les tests charges.  Si le code change, la
contre-epreuve doit etre remesuree et ce fichier reecrit.

Commande dans les deux cas :
    python3 tools/contre_epreuve.py
Code de sortie : 0 dans les deux cas.

Les 12 regles cassee une par une :
  1. frontiere de mot dans la recherche de citation
  2. un nom de fichier n'est pas un symbole (recv.c, /dev/socket)
  3. verification du SHA-256 des pages du corpus
  4. verification du fichier SHA256SUMS
  5. lecture du tableau "described elsewhere" de l'index
  6. extraction de la section Description
  7. statut inconnu pour un symbole hors corpus
  8. deduplication de la liste de symboles
  9. integrite du corpus fige livre
 10. la mention en prose ne vaut que pour un nom qui ressemble a une API
 11. detection des symboles cites en gras
 12. le taux J4 ne compte que les symboles resolus et cites
