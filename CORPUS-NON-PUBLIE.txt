  - le controle anti-fuite (scripts/controle_fuite_corpus.py).

3. COMMENT RECONSTRUIRE LE CORPUS
----------------------------------
  bash scripts/bootstrap_corpus.sh --out corpus-downloaded

Le script telecharge la documentation depuis le site officiel
(https://www.qnx.com/developers/docs/), avec un delai entre les requetes
(1,0 s par defaut), journalise chaque page telechargee dans
<out>/download.log, puis construit le corpus avec le meme outil que le
corpus fige (tools/build_corpus.py).

Le script REFUSE d'ecrire dans un corpus deja fige, et dans tout repertoire
place sous une archive portant le marqueur CORPUS-FIGE.txt.

Temps mesure le 14/11/2026 : 27 pages en 53 s avec un delai de 1,0 s
(soit environ 2 s par page, requete comprise). Pour les 3 426 pages du corpus
complet, il faut compter environ 1 h 55 a ce rythme.

Pour utiliser le corpus reconstruit :

  QX_PORTMAP_CORPUS=$PWD/corpus-downloaded qnx-portmap abort accept bzero

4. CE QUE L'OUTIL FAIT SANS CORPUS
----------------------------------
Le mode par defaut est hors ligne : sans corpus, l'outil ne peut rien
classer et le dit clairement (code de sortie 2). Les tests qui exigent le
corpus complet sont alors SAUTES (jamais en echec) avec le message :

  corpus absent : lancer scripts/bootstrap_corpus.sh

Les tests qui s'appuient sur les fixtures miniatures, eux, passent toujours :
ils prouvent que l'outil fonctionne sur de la documentation QNX reelle.
