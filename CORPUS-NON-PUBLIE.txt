QNX DOCUMENTATION CORPUS - NOT PUBLISHED
========================================

Decision date: 14/11/2026.

1. WHAT IS NOT IN THIS REPOSITORY
---------------------------------
The QNX documentation corpus (3 426 official HTML pages, versions 8.0 and
7.1, 44 942 705 compressed bytes) is NOT in this repository, and is not
redistributed.

The QNX documentation is (c) QNX Software Systems Ltd / BlackBerry Limited.
The official copyright page of the QNX 8.0 documentation, consulted on
14/11/2026, states that the licence information of each file is in the
QNX Software Center, behind a myQNX account; it gives no permission to
redistribute the documentation pages:

  https://www.qnx.com/developers/docs/8.0/com.qnx.doc.copyright/topic/coverpage.html
  (consulted on 14/11/2026)

No request for permission is pending: the corpus is not published.

What this repository contains instead:
  - the CODE of the tool (MIT licence, see LICENSE and LICENCE-DOCS-QNX.md);
  - the TESTS, including 12 MINIATURE FIXTURES (short extracts of 1 to 3
    lines of QNX pages, with source URL and consultation date) in
    tests/fixtures/;
  - the PROCEDURE to rebuild the corpus (scripts/bootstrap_corpus.sh);
  - the anti-leak control (scripts/controle_fuite_corpus.py).

3. HOW TO REBUILD THE CORPUS
-----------------------------
  bash scripts/bootstrap_corpus.sh --out corpus-downloaded

The script downloads the documentation from the official site
(https://www.qnx.com/developers/docs/), with a delay between the requests
(1.0 s by default), logs every downloaded page in
<out>/download.log, then builds the corpus with the same tool as the
frozen corpus (tools/build_corpus.py).

The script REFUSES to write into an already frozen corpus, and into any
directory placed under an archive bearing the CORPUS-FIGE.txt marker.

Time measured on 14/11/2026: 27 pages in 53 s with a 1.0 s delay
(about 2 s per page, request included). For the 3 426 pages of the complete
corpus, count on about 1 h 55 at this rate.

To use the rebuilt corpus:

  QX_PORTMAP_CORPUS=$PWD/corpus-downloaded qnx-portmap abort accept bzero

4. WHAT THE TOOL DOES WITHOUT A CORPUS
--------------------------------------
The default mode is offline: without a corpus, the tool cannot classify
anything and says so clearly (exit code 2). The tests that require the
complete corpus are then SKIPPED (never failed) with the message:

  corpus absent : lancer scripts/bootstrap_corpus.sh

The tests that rely on the miniature fixtures, on the other hand, always
pass: they prove that the tool works on real QNX documentation.
